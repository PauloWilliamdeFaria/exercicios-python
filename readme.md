#  Verificação de Metas de Vendas em Python

Script em Python desenvolvido para prática de estruturas de dados, manipulação de coleções imutáveis (tuplas), controle de fluxo e formatação de dados para o padrão monetário brasileiro (BRL).

---

##  Objetivo do Projeto
Analisar duas coleções de dados (vendedores e seus respectivos faturamentos) e identificar, de forma automatizada, quais profissionais atingiram ou superaram a meta de vendas estipulada de **R$ 3.000,00**.

---

## 🛠️ Tecnologias e Ferramentas
 **Python 3.x**
 **VS Code**
 **Git & GitHub**

---

##  Conceitos Aplicados
 **Tuplas (`tuple`):** Armazenamento de dados ordenados e imutáveis.
 **Cast Explícito (`tuple(zip(...))`):** Pareamento de duas tuplas distintas em uma coleção de pares relacionáveis.
 **Desempacotamento de Tuplas (*Unpacking*):** Leitura direta e limpa de múltiplas variáveis dentro do laço `for`.
 **Formatação de Strings e Moeda:**
   Alinhamento visual dinâmico com f-strings (`:.^60` e `:.<50`).
   Tratamento e conversão de ponto flutuante para o padrão monetário brasileiro BRL via `.replace()`.
